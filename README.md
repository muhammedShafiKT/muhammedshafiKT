## ⚙️ How I Build

- **Layered backends:** router → validation/auth middleware → controller → service → data layer
- **Security first:** JWT access/refresh tokens, HTTP-only cookies, Google OAuth, bcrypt, RBAC, Zod validation
- **Async by default:** long-running work moves to Redis + BullMQ so requests stay fast
- **Ship it properly:** Dockerized services, CI/CD, AWS, and Vercel deployments
